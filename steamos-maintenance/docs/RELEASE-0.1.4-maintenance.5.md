# 0.1.4+maintenance.5

本次维护修订将已经测试的两项性能叠加层修复提供给已安装用户：未启动 OXP3 Fan 时直接读取 oxp_ec 的真实风扇转速；当前内核未提供 RAPL GPU 域时，使用 Intel PMT 的 GPU 能量计数器计算真实功耗。计数器来源切换、重置或采样中断后重新建立基线。

打开维护工具并检查更新，如提示则先选择“仅更新维护工具”。随后选择“CPU/GPU/APU 功耗与 PVRAM 叠加层”，应用更新并按提示重启，让采集进程加载新脚本。无需重装系统。已有自定义叠加层预设保留；回滚可使用维护工具现有的上一代恢复功能，恢复后同样重启。

项目显示版本仍为 0.1.4，内部修订为 0.1.4+maintenance.5。沿用现有正式 Ed25519 公钥，不更换已安装设备的信任。12 个未改变的组件附件及其签名目录引用与 maintenance.4 完全一致，不附带其他插件升级。新增发布准备参数支持验证上一版签名目录后复用完全相同的附件。

验证：Windows 全量 543 项通过、13 项平台跳过；无网卡的离线 Linux 环境全量 543 项通过、15 项平台跳过。独立审查核对签名、完整组件目录及载荷；叠加层实际运行文件仅改变 telemetry.py 与 allow-read.py。已有遥测实机测试由此前修复任务及用户测试完成；本次未新增实机维护升级、重启或恢复验收，源码和离线验证不替代这些验收。

发布后另行核对匿名公开下载、签名、默认 API 与 API 403 后的 Atom 更新发现；对应结果记录在 Release 说明中。历史维护附件保留，Windows 安装器继续保持 Latest。
