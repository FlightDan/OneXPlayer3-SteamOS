# OXP3 SteamOS 1.0.6 — maintenance.16

新增 `lsfg-vk` 可选组件，固定官方 Decky LSFG-VK 0.14.4，默认关闭、依赖 Decky Loader。Windows 新装和维护工具使用同一组选项、同一批原样上游插件文件，包含 LSFG-VK 2.0.0 离线资源与上游许可证。付费 Lossless Scaling DLL 不在载荷中。

首次使用需自行购买并安装 Steam Lossless Scaling，选择 `lsfg-vk` 分支，然后在 Decky 插件中点击 Install LSFG-VK。插件以普通 `deck` 用户安装用户目录运行层。组件部署只管理插件代码，不自动配置游戏，也不覆盖用户的 LSFG 配置。维护恢复只撤回托管插件文件；用户之后安装的运行层、配置、DLL 和游戏设置保留，必要时应先在插件中取消游戏配置或卸载运行层。

组件保持维护器现有 SteamOS 3.10 / build 20260924.1000 / 精确内核基线。项目显示版本仍为 1.0.6，维护内部修订为 `1.0.6+maintenance.16`；插件和运行库版本独立。历史附件不覆盖。公开候选从 maintenance.15 正式源码与载荷单独导出，只移植本次组件变更，排除工作区未公开研究代码和设备记录。

## 实机验收发现及后续修订

本版已公开，附件保留。实机工具升级和 LSFG 首次安装成功，恢复后用户运行层/配置及其他插件设置共 50 个文件哈希不变；但组件空目录残留导致再次安装被误判为非托管目录冲突，重复部署验收未通过。修复使用新的 maintenance.17，不替换本版签名或附件。对应 Windows 新包在完成修复版验收前不发布。
