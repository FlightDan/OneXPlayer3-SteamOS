# 1.0.6+maintenance.4 — 安装识别、窗口授权与完整离线包

2026-10-19。显示版本仍为 1.0.6，维护内部修订为 1.0.6+maintenance.4。构建源码为 `61766b4fa8db247d78ccccecc3402ee6548ff8ce`；发布后的本次改动只更新验收记录，不改变已发布载荷。

修复新装系统缺少维护修订收据时已安装组件被当成未知并默认勾选的问题。以当前槽受保护记录及实际文件识别安装状态，修订更新另行判断；已安装且没有已知更新的项目默认隐藏，未知项不默认勾选。兼容旧版合并安装的 Opti 运行库，并保留中断事务、恢复墓碑、备份不完整及权属冲突的拒绝边界。

启动时优先导入显式离线包，否则按设置自动检查。首次未知安装状态触发只读检测。“一键体检”位于“修复与插件”，结果返回同一页面。大型安装日志使用有界摘要解析；正常 activation.json 与 .activation.lock 不再当成组件目录。

维护窗口使用一次系统授权启动受限特权 helper，同窗口复用，关闭后通过管道 EOF 退出；不保存密码或设置全局免密。旧核心先选择“仅更新维护工具”。首次安装沿用正式签名 Bash 流程。

完整 Windows 包与完整离线维护包均包含 `partition-mount`。KDE 工具让用户选择普通 NTFS、exFAT、ext4、FAT32 数据分区后，按 UUID 保存当前系统槽的 systemd 按需挂载；安装工具本身不选择磁盘。EFI、恢复、加密等不安全分区不可选。保存设置使用该独立工具自己的系统授权。

离线 ZIP 包含全部 31 个可维护组件及依赖、原始签名 manifest、固定公钥的 Bash 入口和旧核心桥接包。完整解压后点开 `OXP3-Maintenance.desktop`，支持触摸，无需终端；首次可能要求 KDE 确认执行，需保持整个文件夹在一起。Waydroid 包含宿主软件包，Android 镜像仍须另行初始化。
