更新、验收和九项交付状态详见 [安装器候选记录](../../windows-installer/docs/RELEASE_1.0.6_X2MINI_HDR_TRIAL.md)。维护器增加同源的 X2mini 用户入口助手，准备载荷时刷新四个脚本；普通恢复、整代回滚和中断恢复均在删除试用运行文件前检查未确认状态和已保存 HDR/WCG。

清理与试用共用锁，持久化禁止新试用的卸载标记。root 只把受保护助手源码交给目标 uid 执行，不运行目标 home 中的脚本。重新安装完成后，规范部署钩子才解除标记；KDE 登录刷新图标不能解除。组件 ID 和维护选项不变。

维护应用 39 文件已重新生成并核对，但完整维护组件包仍被旧 KWin/HDR 和 BMI260 模块阻塞。未用测试签名、未覆盖既有公开附件，未执行实机升级。私有动态功耗研究不进入本候选交付范围。
