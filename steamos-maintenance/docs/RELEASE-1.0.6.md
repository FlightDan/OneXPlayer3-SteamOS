# OXP3 SteamOS v1.0.6 — Maintenance Tools (Bash Installer)

维护版本 1.0.6，同步 OXP3 Light 0.1.1 与 Opti2XMX 0.2.6；增加默认关闭的 Animation Changer 1.3.2 已安装版本路径修复。项目与组件版本分开记录。

Light 修复自动应用及 Steam 下拉菜单导致快速访问面板重建后的设置丢失。Opti 显示不可用原因、保留可执行文件选择，并修复残留安装与重装边界。XMX 原始运行库及 OptiScaler 版本不变。灯光不在加载/唤醒时重放；游戏性能和物理灯色不据软件测试宣称验收。

Animation Changer 修复只接受精确识别的原始 1.3.2 或此前单行路径修复，只写入一个已存在 main.py。设置、动画、前端、元数据和许可证保持；事务再次核对安装身份与先前文件，并保留恢复。未知修改不覆盖。它是维护专用可选项，因为新装仍由用户自行安装第三方插件；维护包不包含完整第三方插件或其 ZIP。

CPU 插件和所有功耗/controls 来源保持 1.0.5 公开版；未包含 CPU 0.3.0 或动态功耗、性能优化研究代码。实机升级只针对本次非 CPU 范围，不降级掌机开发版 CPU。

正式签名身份保持不变。完整目录覆盖所有支持组件；未变化且逐字节相同的分片保留既有公开引用，历史资产不删除。维护 Release 不占用 Latest，Windows 完整安装包承担 Latest。

## 验证与交付

Light 22 后端/10 界面检查通过；Opti 精确提交 CI 通过，独立 ZIP 16 文件与掌机清单一致。新装和维护载荷使用同一最终来源。正式签名产物 complete=true，目录完整覆盖 31 个组件、12 个分片；只有 Opti 插件分片重新构建，另 11 个分片与既有公开附件完全相同并保留引用。Light 和 Animation 兼容代码由签名核心同步。原密钥未变。
