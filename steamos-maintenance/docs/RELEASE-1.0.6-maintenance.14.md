# OXP3 SteamOS 1.0.6 — maintenance.14

修复新装陀螺仪在目标已由系统 `bmi160_i2c` 绑定时直接加载失败的问题。新装和维护修复现在共用已有的可恢复绑定助手：只接管已知陀螺仪设备，失败时恢复原绑定，不卸载共享模块。另补齐新装恢复的失败服务处理：清理未成功时保留助手和组件文件，允许重试。

现有系统无需重装。先更新维护工具，再在组件修复中选择 **BMI260 陀螺仪**；`input` 依赖会一并预检。仅更新维护工具不会自动重装陀螺仪组件。保留 SteamOS 3.10 / build 20260924.1000、精确内核 `7.2.4-valve1-1-neptune-72-g5ab4af5e2eb9`、InputPlumber 0.78.0 和真实硬件检查；不支持的系统继续拒绝，不绕过校准或用户配置冲突保护。

本修订基于公开 maintenance.13，保留已有接管导出和状态说明兼容；不回退到 maintenance.9 的核心。

项目显示版本仍为 1.0.6，维护内部修订为 1.0.6+maintenance.14；Opti2XMX 0.2.8 和 XMX 原始运行库不变。新装脚本、载荷生成、维护准备、离线验证入口已同步。组件 ID、默认项、依赖及中英文选项不变，无需新增安装器界面选项。README 无项目版本变化，无需改动。

新增针对真实载荷生成、绑定失败恢复、失败服务的恢复助手保留、过期助手拒绝等回归测试；独立审查发现的恢复边界和公开源码夹带风险已修正。当前启动实机已确认 BMI260 400 Hz、InputPlumber 接入和虚拟手柄六轴报告持续更新。

本修复不等于已确认反馈用户的全部“映射无响应”原因。Steam 映射激活条件、游戏内跟随、设备运动方向、全新 Windows 写盘、休眠和新硬件仍有各自验收边界。已有公开常规功耗载荷沿用上一版；未公开动态功耗研究、核心算法、内部历史、设备记录、凭据与私钥不得进入本次源码或附件。
