# 1.0.6+maintenance.7 — X2mini / OP3 兼容与 HDR 安全试用

2026-10-21。项目显示版本为 1.0.6，维护修订为 1.0.6+maintenance.7。维护器已正式签名发布，Windows 完整包已构建并上传草稿；公开下载与实机升级状态在下表分别记录。

通用安装、维护、首次启动、CPU/RAPL、遥测、充电、灯光和 HDR 入口取消产品名、厂商及 BIOS 字符串的硬拒绝，继续核对系统、内核、软件版本和实际硬件接口。输入配置根据唯一 MCU 接口生成；BMI260 在初始化及固件上传前核对 ACPI/I2C 与芯片 ID。风扇寄存器布局、HID 报文格式和 HDR 面板检查保留。没有证明两款掌机的全部底层硬件均相同。

X2mini 的 KDE HDR 入口只在规范化厂商和完整产品名精确匹配时安装；未知机型跳过。试用前提示 3 秒，切换后 10 秒未确认自动恢复。独立后台服务负责切换与回退，确认前必须呈现真实 HDR10 首帧；四块灰阶为 100、300、475、700 nit。X2mini 映射为持续 475 / 峰值 700 nit，OP3 保留持续 472 / 峰值 1100 nit。仍要求精确 SDC4301 EDID、内部屏幕、显式启用和固定软件版本；启用外接屏幕时拒绝试用。未确认状态写入恢复日志，下次 KWin 启动前恢复；卸载、整代回滚及中断恢复共用试用锁和持久化禁用标记。

Windows 安装器在安全启动提示关闭时重新读取固件状态；开启或无法确认时不能进入下一步。重启 BAT 和依赖存放在 Program Files 下的独立目录，删除便携安装器后仍可使用；保留用户修改文件并拒绝重解析路径。
