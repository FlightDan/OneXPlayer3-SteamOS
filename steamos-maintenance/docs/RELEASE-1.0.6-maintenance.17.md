# OXP3 SteamOS 1.0.6 — maintenance.17

新增默认关闭、依赖 Decky Loader 的 `lsfg-vk` 可选组件，固定官方 Decky LSFG-VK 0.14.4。Windows 新装和维护工具共享中英文选项、来源与 27 个原样上游文件，包含 LSFG-VK 2.0.0 离线资源及许可证，不包含付费 Lossless Scaling DLL。

首次使用需自行购买并安装 Steam Lossless Scaling，选择 `lsfg-vk` 分支，然后在 Decky 插件中点击 Install LSFG-VK，由普通用户安装用户目录运行层。组件部署只管理插件代码，不覆盖用户 LSFG 配置或修改游戏启动项。维护恢复只撤回托管插件文件，保留用户之后生成的运行层、配置、DLL 和游戏状态；必要时应先在插件中取消游戏配置或卸载运行层。

组件沿用维护器现有 SteamOS 3.10 / build 20260924.1000 / 精确内核兼容基线。项目显示版本仍为 1.0.6，维护修订为 `1.0.6+maintenance.17`；插件与运行库版本独立。来源从 maintenance.15 正式公开基线单独导出，仅移植本次组件与恢复修复，排除未公开研究代码、设备记录和凭据。

## 恢复后重新安装修复

maintenance.16 的实机验收发现：恢复撤回全部 27 个插件文件后，残留空目录树被非托管目录规则拒绝，无法直接重新安装。本修订仅允许复用 LSFG 标准插件路径下完全无文件、无链接的安全空目录树；POSIX 目录须属于 root 且无组/其他用户写权限。非空目录、链接、非 root 或不安全目录继续拒绝，其他插件和 legacy 路径规则保持。旧附件保留。

- 源码与集成：官方 ZIP 固定版本/大小/哈希、生成载荷一致性、Windows 路由/选项、维护事务与签名按需物化完成测试和独立审查。真实 SteamOS Linux 隔离目录中的 5 项新装和 17 项维护测试全部通过，0 跳过，包含安装 → 恢复 → 重新规划 → 安装及真实链接拒绝。生产打包拒绝错误版本、归属、目标、缺失文件与变化字节。
- 正式维护产物：复用原 Ed25519 身份；完整目录覆盖 33 个目录项、32 个可维护组件、15 个分片。最终核心和完整离线包验签、全文件/引用、CRC、空缓存物化通过。7 个当前附件与 16 个引用附件均从公开入口匿名重新下载、核对签名及哈希，API / Atom 均能发现修订 17；15 个历史分片引用保持不变。
- 实机维护升级：已安装正式工具 1.0.6 → maintenance.16 → maintenance.17，通过正式签名工具完成 LSFG 安装 → 恢复 → 重新安装 → 重启，未手工清理空目录。重启后 27 个插件文件符合官方哈希，其他插件/设置及用户 LSFG 运行层/配置共 50 个受保护文件哈希保持一致，原信任不变、系统只读、相关服务正常且无待恢复事务。Decky 识别 0.14.4，用户运行层 2.0.0 健康检查与 9 个用户文件归属权限通过。
- Windows 最终包：编译 0 警告/0 错误；独立 ZIP 审查 18 项和打包后发布冒烟检查 15 项通过。LSFG 27 文件、维护工具 42 文件符合最终来源，其余 17 个集成组件清单及 109 个载荷与上一正式公开基线一致。公开完整包已重新匿名下载，大小、SHA-256、CRC、版本和源码标识通过核验。
- 边界：未执行全新 Windows 整盘安装；测试机未配置付费 Lossless Scaling DLL，未测试游戏补帧或性能。先前旧版 root 所有旧库的权限错误仅是隔离复现，不能据此确定截图设备的唯一原因。
