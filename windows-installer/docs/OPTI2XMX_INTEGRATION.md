# Opti2XMX 0.2.1 安装集成

安装器将 Opti2XMX 列在自研修复组，默认勾选，可关闭，依赖 Decky。游戏的 XMX 与 Opti 注入开关独立；安装插件不会自动接管已有游戏，也不会自动开启游戏功能。

插件包含研究会话 01a134f7-1192-7db0-9a54-841a1d284e8c 的 0.2.1 源码与构建前端，包括 opti.py、真实 Intel 设备身份修复、Opti 版本安装/迁移/回退及中英文界面。Opti 0.9.4 游戏注入文件由用户在插件中选择后下载；官方源为默认，备用镜像标明第三方。

离线携带 20261005 XMX 运行库、IGC 2.10.10、ocloc 25.18.33578.6 与官方 XeSS SR 2.0.2.68，安装于 /opt/oxp3-opti2xmx/20261005。仅从已有资源按明确白名单收集公开文件，排除游戏状态、用户配置和已生成内核缓存。来源记录在 cache/integration/sources/opti2xmx/PROVENANCE.json；运行库和 XeSS 许可随归档保留。

Decky 后端以普通用户运行。大运行库使用同文件系统目录事务，插件文件使用原件日志。移除前须在插件内恢复 XMX 和卸载受管理的 Opti 游戏配置；关闭注入不等于已卸载。原有游戏文件、启动项和备份由插件逐游戏管理。

研究会话已记录用户确认《黑神话：悟空》原生 XeSS FG 在 XMX 开、Opti 注入关时工作；这不代表其他游戏或新装系统完成实测。新装仍须检查 Decky 加载、游戏启动项、首次 XMX 编译、关闭/恢复与休眠。

语言跟随 Steam 页面语言，浏览器语言作后备；非中文显示英文。CPU、Fan、Battery 保留各自的中英文文案和浏览器语言选择。本地语言渲染与安装资源逐字节同步检查不等同于掌机界面验收。
