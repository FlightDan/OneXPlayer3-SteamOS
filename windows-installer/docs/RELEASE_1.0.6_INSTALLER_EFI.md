# Windows 1.0.6：EFI 复核与进程等待修正

2026-10-19。基于公开源码 `48ece6e736ab07786b2cc7a7359aad6a15b956b0` 的新安装器构建；显示版本仍为 1.0.6，公开时使用新时间戳和新 Release 标识，不覆盖历史附件。

修复组件复核阶段 `AssertionError: efi/EFI/steamos/grub.cfg`：EFI 是独立分区，旧复核仅在 GM7 专项修复适用时挂载它，普通硬盘或 SD 目标上的 split-lock 启动文件因此被误判缺失。现在按实际成功安装的组件文件挂载当前 A/B 槽的 EFI，并以只读方式复核，不依赖硬盘型号；部署阶段也支持仅选择 split-lock 时挂载 EFI。GM7 型号条件仅用于其特定 NVMe 休眠参数，不限制其他磁盘的组件安装。

修复解压、镜像转换等子进程在日志回调或输出读取异常后的等待：及时终止并回收本次启动的子进程，保留失败原因，避免输出管道塞满后一直等待。构建环境的输出读取异常也及时终止对应子进程。既有构建环境内部超时改为包含任务名、时限和日志位置的明确失败；用户取消保持取消语义，原有时限不变。

新安装默认勾选 rEFInd，默认进入 SteamOS，菜单等待 2 秒。可手动取消、选择 Windows 或调整等待时间；新装 CLI 和配置示例同步 2 秒。固件启动顺序仍按既有内置/外部盘规则处理；不会通过维护升级改写现有启动菜单设置。
