# 0.1.4 更新清单与验收

本页记录 2026-10-16 新增集成及验收范围。完整 Windows x64 安装应用 ZIP 通过 Releases 提供，不包含 SteamOS 系统镜像。
维护修订 `0.1.4+maintenance.3` 已先行发布，公开下载、签名验证及本机 0.1.3 → 0.1.4 的 26 项组件升级和正常重启验收完成；中间失败、修复和测试边界完整保留在[维护验证记录](https://github.com/FlightDan/OneXPlayer3-SteamOS/blob/v0.1.4/steamos-maintenance/VALIDATION.md)。以下各专题的原有硬件验收范围继续适用，不等同于完整无人值守全新安装验收。

## Split-lock 报告修复

安装器与维护工具新增默认选中的 `split-lock`，添加 `split_lock_detect=off`，重启后生效。
源自 kas5852 的上游 PR #16 和 20261015 修复包，保留 HANA & Claude 版权声明和完整 MIT 许可。
与 GM7 同时选中时，组合引导文件由单一事务所有者保存；共同恢复必须显式选择整个恢复组，
有外部改动时在写入前拒绝，防止恢复一半。

实机普通重启已确认参数生效；启动后约 17 分钟检查 manager/内核相关警告均为 0。
精确清除 311,510 个 `type=split_lock` JSON 报告，释放 1,275,944,960 字节实际空间。
其他 5,247 个文件的内容和元数据摘要前后完全一致；报告提交服务、手柄与 Decky 均保持正常。
清理不按文件名或文本片段推断类型，不删除其他报告、二进制或无效 JSON。
新安装及维护安装不隐式执行历史报告清理。

实现与恢复说明见 [split-lock 组件](../components/split-lock/README.md)。

## OXP3 Light

新增默认选中、依赖 Decky 的三分区控制插件：配对的左右摇杆灯环、Xbox 按钮灯、背部标语灯。
提供独立开关、颜色预设、自定义 RGB 和亮度，中英文原生 Decky 控件。
排序为 CPU → Fan → Battery → Light → Opti2XMX → Restart into Windows；更新时只插入缺少的 Light，
保留其他插件的相对顺序及显式排序偏好。

当前精确 7.2.4 底座使用已核实的 HID v1 厂商接口 02；旧驱动的单个灯环占位接口不当作三分区原生支持。
只发送两类灯光帧，不初始化按键表、不写拦截或手柄模式、不重新绑定驱动。
保留 HueSync（honjow / HHHHanasak1）和 HHD（Antheas Kapenekakis）的固定来源、原作者及完整 BSD/LGPL 许可。

实机真实面板逐项操作：灯环紫色、Xbox 白色、标语蓝色，均为 60% 亮度，三项写入成功；
界面没有错误，`gamepad_mode=xinput`、M1/F16、M2/F17 均与测试前一致。
这些测试确认控件/RPC/设备写入链路；旧 HID 协议没有状态读回，因此未自动验证肉眼显示颜色。
目前只提供纯色，不自动重放开机或休眠后的灯光设置；加载和卸载插件本身不改灯光。

来源、API、限制与测试命令见 [OXP3 Light](../components/light/README.md)。

## 串口重复报错修复

关闭默认不可用的 `serial-getty@ttyS0` 登录服务，停止其终端错误和反复重启。
保留内核 `console=ttyS0,115200` 输出及其他终端；有意使用串口登录时，仍可通过
`oxp3.serial-console=1` 显式启用。原件及原有服务状态保留供恢复，不清理其他日志。

已接入 Windows 安装器的 A/B 两槽部署、运行库依赖、安装进度与结果校验。
本机现有系统已应用。Bash 维护组件 `serial-console-policy` 已加入，
当前槽位的应用、收据和恢复在隔离 Linux 测试通过；正式入口实机升级与重启验收随后进行。

## AutoFlatpaks 电池状态兼容修复

修复包版本为 `1.6.8+oxp3.1`。Steam 电池状态尚未初始化时继续等待，避免直接读取
不存在的 `SystemPowerStore.batteryState`；兼容状态延迟出现、消失后恢复及插拔电源，
插件卸载时清理轮询定时器。

保留 0.1.4 第三方插件由用户自行安装的策略，不恢复 AutoFlatpaks 默认预装，
也不把它重新加入维护工具的默认分发目录。修复包构建和旧部署兼容路径已验证；
Bash 维护入口提供可选 `autoflatpaks-compat`：只对精确匹配的已装版本修复前端和版本元数据，
保留设置、后端与许可证；未安装或被自行修改的版本拒绝处理，不安装完整插件。
规划、收据、事务、恢复和并发变更拒绝已通过隔离 Linux 测试。

两项修复均已在当前设备应用，仅单独重载 AutoFlatpaks，未重启 Decky 主进程。
连续观察 336 秒，串口错误和电池状态空对象错误均无新增；4 项插件脚本/归档测试、
5 项隔离 Linux 部署/恢复/冲突测试通过，Windows 构建零警告、零错误。
尚未完成重启持久性及全新安装启动验证，短时观察不代表长期无报错。
