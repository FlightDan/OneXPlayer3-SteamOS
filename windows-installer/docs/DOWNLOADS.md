# 镜像下载

按 2026-10-14 当前代码维护。操作入口见 [安装指南](INSTALLATION_GUIDE.md)，包与源码差异见 [README](../README.md)。

原生 WPF 安装助手内置 aria2c 1.37.0 Windows x64。无需单独安装下载器。在线下载卡片默认选择官方 ZIP，也提供官方 BZ2 和自定义 HTTPS 直链；下载完成自动填入本地镜像路径，再由现有准备流程解压、部署。下载器不会写入物理磁盘。

## 下载与恢复行为

主向导“准备系统”展开为“恢复镜像”和“3.10 镜像”。恢复镜像页保留 aria2 的 ZIP（推荐）/ BZ2 / 自定义来源、暂停续传和重新下载行为；两页都提供“复制地址 · 手动下载”和本地文件选择。

3.10 页使用固定官方 `.raucb` 更新包地址。在线下载或选择本地 `.raucb` 后，只读取更新包信息并保存到 `<工作空间>/steamos-3.10/system.raucb`，自动显示本地路径，允许进入下一步。系统数据块的联网获取和 `rootfs.img` 重建延后到“开始安装”的准备阶段；不能仅凭更新包已下载就认为整份系统已离线可用。导入已重建的 5 GiB `rootfs.img` 时保存工作副本，安装准备仍核对实际系统版本与内核。

本地导入无需勾选在线下载条款，结果显示在文件选择附近。安装时 `01.02.01` 区分本地读取和在线下载，`01.02.03` 显示“重建系统镜像”；百分比和 5 GiB 表示已重建量，不是网络传输量，已有数据可复用。

恢复镜像页的下载记录与 3.10 更新包不是同一种下载任务。`.raucb` 不属于恢复镜像页支持的 `.img` / `.img.bz2` / `.img.zip`，应在“3.10 镜像”子页选择；不要改扩展名。3.10 更新包下载使用 HTTP 客户端，重建阶段使用 desync；恢复镜像使用下文的 aria2 续传机制。

- 高级工具的“官方恢复镜像”也接入同一下载器：下载按钮右侧选择官方 BZ2、ZIP 或自定义 HTTPS 镜像源；进度、百分比、速率、剩余时间及暂停/重新下载均在按钮下方。
- “复制下载地址（自行下载）”复制当前所选入口或填写的自定义 HTTPS 直链，无需等待可用性检测，不启动下载；外部下载完成后可通过“选择文件”导入。
- 打开高级工具时并发检测预置镜像链接（Range GET，每项最多 8 秒），优先选择可用的官方 ZIP；ZIP 不可用时选择其他可用入口。显示可用性与响应毫秒数，保留检测期间的手动选择。它检测实际下载地址，不依赖 ICMP ping；响应时间不代表持续下载速度。全部不可用时可重试或填写自定义源。
- 镜像导入时明确指定 ZIP / bzip2 外层格式，避免自动展开镜像内部文件系统。选择 .bz2 镜像时，安装进度的准备系统阶段显示解压可能需要较长时间的提示；ZIP / 原始 .img 不显示该提示。

- 用户阅读并接受下载条款后才开始下载；默认不勾选。
- 固定版本 URL，单任务最多 4 路连接，证书验证保持开启。
- RPC 只监听本机，并使用每次启动生成的令牌；aria2 随安装器退出。
- 暂停通过 RPC 正常退出并保留 aria2 控制文件。重新打开后点击“下载 / 继续”恢复。
- 更换 URL 使用独立目录；“重新下载”创建新记录，保留旧记录。
- 续传前比较服务器提供的强 ETag / Last-Modified、长度和最终 URL。来源改变或无法安全续传时要求重新下载。
- 完成后核对长度及格式头，发布记录支持重启恢复。这里不是文件真实性证明；后续仍需现有镜像导入和准备检查。
- 不新增摘要、校验和或指纹验证；禁用 aria2 BT/Metalink 跟随和完整性摘要校验。
- 下载缓存位于 `<工作空间>/downloads/<任务 ID>`，默认工作空间是工具目录下 `work`。切换工作空间不会搬移旧记录，续传旧任务时切回原目录；空间不足会明确报错，当前尚无自动缓存清理界面。
- 自定义 URL 必须使用 HTTPS，路径以 .img、.img.bz2 或 .img.zip 结尾。HTTP loopback 仅供本地开发测试。
