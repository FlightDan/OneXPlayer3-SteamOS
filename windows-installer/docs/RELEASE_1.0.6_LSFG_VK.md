# OXP3 SteamOS 1.0.6 — LSFG-VK 可选组件

新增默认关闭、依赖 Decky Loader 的 `lsfg-vk` 选项，中英文界面均显示官方插件版本 0.14.4 及首次使用要求。载荷固定官方 ZIP 的 5,322,847 字节和 SHA-256 `a2187926dfb53e1813fa786d6e12a1d078638aa27153061389b755806e97338f`，保留全部 27 个插件文件及上游许可证；包含官方 LSFG-VK 2.0.0 离线资源，SHA-256 `08bdbdf373a111022df87dac7aa87e3b564bb841f961552e3ca85fea12b5aa74`。

安装器只部署受托管插件代码。用户先自行购买并安装 Steam Lossless Scaling，切换 `lsfg-vk` 分支，再在 Decky 插件中点击 Install LSFG-VK，由插件以 `deck` 用户安装运行层。不会分发付费 DLL、覆盖用户 LSFG 配置或修改游戏启动项。恢复仅撤回托管插件文件，保留用户之后生成的运行层、配置和游戏状态。

本轮项目显示版本不变，维护修订对应 `1.0.6+maintenance.16`，Windows 完整包需使用新的时间戳和正式源码提交标识，不覆盖历史附件。

针对性源码测试、载荷一致性和生产打包拒绝夹具已完成；最终独立审查、Linux 新装集成、签名维护升级、最终完整包及公开下载验收按维护 Release 记录更新。先前本机插件/运行层安装测试不代替本次最终产物验收；尚未测试游戏补帧性能。
