# OXP3 SteamOS 1.0.6

本次更新同步掌机已验证的非 CPU 插件。项目版本为 1.0.6；SteamOS、插件及 XMX 运行库保留各自版本。

- OXP3 Light 0.1.1：滑块结束调整后自动应用；颜色预设及开关立即应用。修复 Steam 下拉菜单重建快速访问面板时丢失自定义 RGB 和草稿；区域写入串行处理，失败可重试。标语灯显示为顶部标语灯。仅纯色；不在启动或唤醒时自动重放。
- Opti2XMX 0.2.6：同步已在掌机使用的版本，显示安装/XMX 不可用原因，保留游戏与可执行文件选择；修复缺失代理的残留安装及卸载后重新安装边界。XMX 运行库仍为 20261005，OptiScaler 仍为 0.9.4。公开独立源码为 f2e5c4ca045dc584a24a0cf5ea27002ca8f1ba37。
- Animation Changer 1.3.2：维护器提供默认关闭的已安装版本路径修复。既有 Steam root（包括自定义或悬空链接）在每次使用时解析；首次启动尚无 root 时使用 Steam 数据目录。仅修改精确识别的 main.py，保留设置、动画、前端、元数据及原许可证，可通过维护事务恢复。支持原始及此前 canonical-path 单行修复；其他修改保留并拒绝覆盖。
- OXP3 CPU 保持正式 1.0.5 的 0.2.0；native-tdp、所有 controls 代码及其载荷保持原公开版本。不包含 CPU 0.3.0、动态功耗调度、性能优化研究或核心算法。

## 安装与升级

新装安装脚本和维护升级使用同一批 Light/Opti 文件。第三方插件继续自行安装；安装包不携带第三方插件 ZIP，不恢复已退役的新装选项。Animation Changer 修复是维护专用的可选项，只针对已经安装且精确匹配的 1.3.2，不安装完整插件。

CPU、风扇、电池及其他未更新组件保留 1.0.5 正式载荷。保留 1.0.5 的非关键安装检查降为提示修复。既有公开版本和附件不覆盖。

## 验证边界

Light 22 项后端及 10 项界面回归通过；掌机已有最终 0.1.1 文件与本次来源一致，先前实际界面检查涵盖自动应用和 RGB 选择保持。灯光硬件无颜色读回接口，不把只读发现成功写为物理颜色验收。

Opti2XMX 准确源码提交的 GitHub CI 39123287558 通过；包含 169 项 Linux 测试、类型检查、构建和界面回归。最终独立 ZIP 的 16 个文件与掌机只读清单完全一致；三份文本文件保留已验收 ZIP 的 CRLF，提交源码使用 LF，归一后相同。未包含后续未部署的标签修改。

维护全量回归：正常 Windows 用户环境 564 项（543 通过、21 跳过）；离线 Linux 564 项（549 通过、15 跳过）。Linux 另运行 Installer Animation Changer 8 项，全部通过，包含真实链接及恢复检查。独立事务/安全审查通过；修正回滚测例后再次验证。Windows 构建 0 警告/0 错误，11 项发布 smoke 通过；32 份随包维护文件及全部插件载荷同步检查通过。最终正式签名目录包含 31 个支持组件和 12 个分片；CPU 及其他 11 个未变化分片精确复用历史公开引用。

本记录不声明全新系统安装、游戏性能、重启或休眠验收。公开下载完整性与实机升级结果以对应 Release 验证记录为准；它们与源码回归分别记录。
