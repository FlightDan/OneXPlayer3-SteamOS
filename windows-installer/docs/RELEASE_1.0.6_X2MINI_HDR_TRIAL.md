# 1.0.6 X2mini KDE HDR 安全试用源码候选

2026-10-21，分支 `release/x2mini-op3-compat`。未发布；主版本仍为 1.0.6。

为 X2mini 增加 KDE 桌面试用入口。双击后先提示 3 秒，独立用户服务就绪后才允许切换 HDR；10 秒内没有明确确认、关闭对话框或程序退出时恢复原 HDR/WCG 设置。只有原生 HDR10 程序成功呈现首帧后才接受确认。四块灰阶分别标示 100、300、475、700 nit，供用户检查画面和亮度层次，不能替代仪器测量。普通图片或浏览器色块不能冒充 HDR 验收。

固定 KWin 的 X2mini 参数改为持续 475 / 峰值 700 nit；OP3 的既有 472 / 1100 参数保留。仍要求精确 SDC4301 面板 EDID、内部屏幕、显式 opt-in 和固定软件版本。连接启用的外接显示器时拒绝开始试用，避免确认了错误屏幕。后台服务是切换和回退的唯一执行者；前台只提交请求，避免超时后的迟到命令重新打开 HDR。

KWin 本身会写入显示设置，因此试用期间使用持久化日志跟踪未确认状态；超时回退核对实时和磁盘设置。退出或崩溃后仍未回退成功的状态在下次 KWin 启动前恢复。只有确认后才保留设置。该机制依赖用户 systemd 会话、KDE 工具和重编后的原生运行时；不是掉电时仍能运行的计时器。

新增入口只在实时 DMI 规范化厂商为 `ONE-NETBOOK`、完整产品名为 `ONEXPLAYER X2 Mini` 或 `ONEXPLAYER X2 Mini PRO` 时安装；不使用子串，也不以板卡名代替产品名。安装未知机型时不写桌面入口。当前本地记录只有驱动模态别名 `dmi*:rvn*ONE-NETBOOK*:rn*ONEXPLAYERX2MiniPRO*:`，这是板卡匹配记录，并非 X2mini 实机 sys_vendor/product_name 原始采集。引用聊天目前读取失败，不能宣称昨天的规划已经确认实机字段。上述产品别名是保守候选，真实机器字段不同会跳过安装，仍需实机核对。

脚本在 `components/desktop-hdr/hdr_trial.py`，安装入口为同目录 `install-x2mini-hdr.sh`；后者针对已部署的运行时创建用户入口，不能独立安装旧 KWin 来实现新功能。维护器和安装器使用受保护的同源设备助手管理入口；root 不执行目标 home 里的 Python。恢复组件前持久化卸载标记并与新试用共用锁，覆盖普通恢复、整代回滚、崩溃队列和隐式恢复。登录不能解除标记，只有完整组件重新安装成功后的规范部署钩子可以解除；手工修改的图标保留。
