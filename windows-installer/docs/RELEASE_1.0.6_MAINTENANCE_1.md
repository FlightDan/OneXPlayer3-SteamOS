# OXP3 SteamOS 1.0.6 — 维护工具与槽位切换更新构建

项目显示版本保持 `1.0.6`，维护渠道修订为 `1.0.6+maintenance.1`。安装包使用新的构建时间和源码提交，不覆盖已经公开的附件。

## 更新内容

- 随附维护器新增只读一键体检和诊断 ZIP 导出，检查手柄枚举、InputPlumber、输入配置、维护记录与实际文件差异。
- GitHub 下载默认自动回退，设置可选官方直连、gh-proxy.com、ghfast.top、ghproxy.net；下载继续验证签名、大小及哈希。
- 维护器和槽位切换优先读取 KDE 界面语言，中文界面可搭配英文区域格式。
- 槽位切换直接显示目标槽确认，确认后仅当更新检查服务运行时再询问是否停止并重启。取消不修改系统；正在运行的 RAUC 仍禁止强行停止。

安装组件 ID、默认选择和新装依赖沿用 1.0.6。槽位切换从当前最终源码部署；随附维护器通过 `prepare-maintenance.py` 重新生成。其他组件沿用已公开的 1.0.6 功能基线，不引入尚未授权公开的功耗研究代码。
