# OXP3 SteamOS 1.0.6 — Opti2XMX 0.3.0

新装与维护统一携带 Opti2XMX 0.3.0。每游戏“超分输出”可选择 XeSS 或 FSR 4.1.2 Lite XMX；默认 XeSS，FSR 需自行导入原始本地模型 ZIP。公开包不包含用户模型或 Microsoft Cabinet DLL。

安装选项的组件 ID、默认选择和 Decky 依赖保持一致。固定的 Opti 0.9.4、0.7.9 和 Opti 10 nightly-20261025 三份原档进入离线载荷；仅开源解压适配器及其依赖、源码和许可新增到插件。维护器与 Windows 安装器使用相同插件文件、版本和哈希。

FSR 的实机配置、恢复验证与测试范围见 [维护修订记录](../../steamos-maintenance/docs/RELEASE-1.0.6+maintenance.19.md)。新装不会导入私人模型、启用游戏 FSR 或修改游戏原设置。最终签名维护升级、安装器构建和公开下载结果以匹配 Release 记录为准。
