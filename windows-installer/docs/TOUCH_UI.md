# 触屏安装界面

当前代码：2026-10-14。七步流程为“安装位置 → 准备系统 → 选择安装内容 → 确认方案 → 启动器安装 → 安装进度 → 完成”，用户操作见 [安装指南](INSTALLATION_GUIDE.md)。

## 布局与导航

- 默认最大化，保留 Windows 标题栏与任务栏空间。F11、最大化时按 Escape 可切换窗口状态；左下角仅保留横跨两列的“退出”按钮。
- 左侧为步骤和中英文切换；中间是可触摸滚动的内容区，底部导航固定。磁盘表随内容增长，避免额外的纵向滚动区域。
- 窄窗口隐藏次要分区列，状态文字换行；位置卡片按宽度并排或上下排列。主要控件至少 48 DIP 高，分区行 52 DIP。
- 已完成配置显示绿色；“选择安装内容”首次进入且配置有效后才显示绿色。尝试离开仍未完成的步骤显示红色，可返回修正。预览进度页不会开始安装，最终仍检查前置条件。
- 详细日志默认折叠，点击后展开并随可用高度扩展；进度标题与进度条采用紧凑间距。界面仅保留最近一部分输出，进度/结果页可导出完整任务文本记录的 ZIP。
- 选择安装内容页移除底部“安装说明”；启动器页仅保留 rEFInd 安装选项，勾选后展开启动设置，不再提供独立预览与导出入口。

## 工作空间、调试与容量

前五个配置页中显示所选工作空间、可用空间和准备预算，可选择本地专用文件夹。下载、读取磁盘或安装进行中不可切换；切换不会搬移旧文件。

调试模式默认关闭，开启后显示高级工具、示例布局与开发镜像选项。关闭会清除示例选择和开发镜像模式，保留真实磁盘列表。调试开关不会将实际安装变成演练；演练使用 `--rehearsal`。

实盘容量默认 64 GiB，当前源码提供 64G / 100G / 使用全部空间与自定义输入。空间不足时禁用对应快捷选项，显示 home 大小与未分配余量。后端准备镜像扩容后必须与选择精确匹配。历史 013814 ZIP 没有容量扩展和日志导出更新，见 [README](../README.md)。

## 安装与删除确认

普通启动为真实安装，没有模式复选框。第一次从位置页继续时，确认框显示目标型号、磁盘号、起点、所选容量与格式化范围；取消保留选择，继续只进入准备页。修改选择会使旧确认失效。

方案页还需单独勾选备份和格式化确认。确认项加粗并有边框；未勾选点下一步会滚动、聚焦，并在系统允许动画时提示边框；勾选后清除提示。第 5 步点击“开始安装”才启动流程。

“删除选定分区…”是另一项立即执行的操作，有自己的管理员确认和保护检查。安装退出或停止不能撤销删除。安装时保留刷新后仍存在的分区，不支持整盘擦除。

## 检查与验收边界

`--touch-checks` 使用合成快照运行 WPF 布局与路由事件检查，不执行磁盘安装。覆盖中英文七步和 640×360 至 1920×1080 的逻辑尺寸；检查固定控件、滚动可达、组件列、引导选项、调试入口、工作空间、容量快捷项、确认提示与日志导出。

已有最新记录 `logs/touch-ui-20261014-020827/checks.json` 为 1,109 项断言、98 组布局通过。PNG / SVG 为原生控件渲染和布局证据，不能代替掌机手指滑动、惯性、高 DPI、固件触屏与实体输入验收。

其他入口包括 `--options-checks`、`--wizard-checks <prepared.img>`、`--cli partition-picker-checks`。更多证据见 [当前实现状态](../IMPLEMENTATION_STATUS.md)。旧开发构建和截图流水账已移至本地归档区。
