# 初始密码与公共目录权限修复

记录日期：2026-10-14。以下为已有本地回归记录的公开摘要，原始日志保留在开发工作区。

设置初始密码时，原任务把 `umask 077` 应用于后续整个流程，导致部分公共运行目录及默认生成文件无法由 `deck` 用户访问。

当前任务使用 `umask 022`，仅写入密码文件的子进程使用 `077`。组件目录落实明确的权限，包括桌面运行资源的嵌套目录；写盘前的 A/B 集成复核在 chroot 后切换为已安装 `deck` 的 UID、GID 和附加组检查实际访问。

已有本地记录包含带密码、不带密码、权限拒绝、事务与组件回归，以及后续非特权访问和限制性 umask 检查。最终本地应用构建为零警告、零错误。

检查在隔离的本地 QEMU 临时文件系统中进行，不代表完整实盘安装、首次启动或设备功能已通过。此修复不会自动修复已安装系统或旧准备镜像；既有实机状态仍需另行处理。
