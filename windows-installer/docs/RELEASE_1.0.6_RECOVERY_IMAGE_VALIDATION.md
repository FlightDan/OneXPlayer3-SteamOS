# 1.0.6 Windows 安装器：恢复镜像前置校验

更新日期：2026-10-22。显示版本沿用 1.0.6；最终 Windows 安装包须使用独立构建时间戳，并绑定最终 main 源码提交。

## 行为

- 在“恢复镜像”页点击“下一步”时检查未压缩 `.img` 的实际内容。误选单独 Btrfs 系统分区镜像（包括改名后的 `rootfs.img`）会留在当前页，中英文提示说明应选择完整 SteamOS 恢复镜像，并把该系统分区文件导入“3.10 镜像”。仅文件名为 `rootfs.img` 的合法恢复磁盘不会被误拒绝。
- 校验主 GPT 头和分区表 CRC、边界、分区标识及五个恢复分区 `esp / efi-A / rootfs-A / var-A / home` 的顺序和非重叠范围。读取量有固定上限，不扫描镜像内全部文件；这不是分区内容、备用 GPT 或来源真实性验证，虚拟机中的系统版本和内核验证继续保留。
- `.img.zip` / `.img.bz2` 保留现有导入方式，在解压完成后、转换镜像和启动虚拟机之前执行相同校验。安装控制器、官方 3.10 准备和直接 `upgrade-source` 调用入口同步检查。使用本工具预部署镜像的分支保持原有专用校验。
- 不新增安装选项、组件 ID、默认选择或 Linux 维护功能；不修改已有镜像和真实磁盘。
