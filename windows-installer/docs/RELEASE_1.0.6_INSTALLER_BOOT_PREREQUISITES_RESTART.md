# 1.0.6 安装器候选：安全启动实检与持久重启脚本

日期：2026-10-21。分支：`release/x2mini-op3-compat`。本地源码与应用构建已更新，未创建或发布新的完整安装包。兼容分支复核另发现固定 KWin/HDR 运行时仍带旧 DMI 门禁；已移除源码硬拒绝并加入安装器准备、维护载荷准备和最终打包的旧二进制阻断，待 KWin 重编，详见 [兼容候选记录](RELEASE_X2MINI_OP3_COMPAT_CANDIDATE.md)。

## 本次行为

- 显示安装前准备提示时，直接读取 UEFI `SecureBoot` 变量；用户勾选确认并点击进入安装位置时再次读取。只有单字节 `0` 才通过。开启、缺失、读取异常、非 UEFI 或权限不足都会显示原因并保留遮罩，不允许下一步，也不开放磁盘读取。既有正式安装前固件及 BootOrder 检查保留。BitLocker 恢复密钥仍由用户自行准备，本次不修改 BIOS 或加密保护。
- 新装和中断恢复成功后，把完整、自包含的重启 BAT 写入 `%ProgramFiles%\OXP3 SteamOS\Boot`（通常是 C 盘 Program Files）。桌面 BAT 使用编码后的绝对路径调用它；自提权也继续引用该持久副本。之后不依赖安装器 EXE、部署 JSON、工作目录或其他随安装器删除的文件。
- 重复生成幂等；保留已有用户文件和管理员编辑，冲突时使用独立文件名。持久程序目录及其祖先拒绝重解析点，用户重定向桌面继续受支持。持久脚本或桌面入口创建失败仍作为结果页 warning，不把已完成的磁盘写入改判为失败。旧安装包和已生成的旧入口不会自动迁移。
