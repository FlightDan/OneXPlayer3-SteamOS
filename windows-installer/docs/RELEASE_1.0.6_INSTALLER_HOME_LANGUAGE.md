# Windows 1.0.6：home 复制优化与安装语言

2026-10-20。显示版本保持 1.0.6；本轮使用新的源码提交、构建时间戳和安装包，不覆盖已经公开的构建。

承接空间预检、主安装日志、管理员助手早期异常记录及隐藏“使用全部空间”入口的修复。本轮新增两项变化：

- 实际磁盘新装在 home 扩容及所有离线修改完成后，使用随包 e2fsprogs 1.47.3 在只读、未挂载的源分区上执行 e2fsck -fn 和 dumpe2fs，生成 ext4 已分配块复制计划。只跳过文件系统明确标记为空闲的块；文件系统元数据、日志、inode 表、备份和已分配的零块仍写入并完整读回校验。其余七个系统分区保持完整复制。64G、100G 及自定义容量均使用这条路径；未知但有效的特性回退完整复制，损坏、待恢复或外置日志的文件系统拒绝写盘。
- 安装器的系统与 KDE 语言默认跟随安装器语言，手动选项优先。离线部署同时设置 A/B 根系统的 /etc/locale.conf 的 LANG、LC_MESSAGES，以及共享 home 中 plasma-localerc 的 Translations/LANGUAGE 和 Formats/LANG、LC_MESSAGES。保留其他配置及独立区域格式，继续使用既有语言组件事务和恢复记录。选择“保持系统默认”时不修改语言。Steam 客户端的账户语言仍由 Steam 管理。

父进程先在锁定的源镜像上生成复制计划，管理员助手再次独立生成，模式和 SHA-256 必须一致才允许写入。新物理安装任务与恢复日志使用 schema 2 绑定计划；旧 schema 1 会话继续执行原来的完整复制和完整比对。完成分区复验、断点恢复、进度统计均沿用本次绑定的范围，不能把旧完整复制记录自动改成优化模式。源镜像的文件身份和分区几何仍须一致。

这项优化减少目标盘读写，不等于安全擦除磁盘，也不改变用户选择的 home 容量。临时镜像在属性中仍可能显示很大的逻辑大小；实际分配取决于文件系统元数据和已有内容。本轮保留既有会话和恢复数据，不自动清理旧任务。

## 验证记录

- Windows 构建、原生范围及恢复检查、完整安装包 smoke、独立审查和交付校验分别记录在构建证据中。新增普通文件检查覆盖已分配零块覆盖、空闲区跳过、边界、损坏、取消及旧/新日志兼容。
- 已完成隔离 QEMU 中的真实 ext4 默认、casefold/orphan_file、64 GiB 和 100 GiB 夹具。目标文件先写入非零残留，验证已分配零数据和零 inode 表会覆盖残留，空闲块被跳过；重建后通过 e2fsck -fn，零文件可正确提取。
- 空白 ext4 夹具的复制量：64 GiB 为 1,671,999,488 字节，100 GiB 为 2,287,108,096 字节。这是 home 文件系统测试数据，不是完整安装的总读写量；其他七个系统分区的复制和已有文件仍计入总量。
- 已接受的实际 3.10 测试镜像只读分析：home 总计 42,547,019,776 字节，计划保留 784,728,064 字节、113 个范围。实际收益随已有数据变化。
- 原始 3.10 根镜像已有提供的全部 UTF-8 locale 和 KDE 中文翻译；系统默认 LANG 为 en_US.UTF-8。本轮不能据此宣称 C/POSIX 是用户机器的已证实故障原因。
- 完整 owned VHD 验证通过：实际 Windows GPT 追加、已选卷锁定、八个分区迁移写入及读回、非零残留探针、已分配块损坏拒绝、空闲块差异接受、既有分区保持；独立 UEFI 启动进入 SteamOS 7.2.4 串口登录提示。另一个只读 Linux guest 对迁移后的 home 再次执行 e2fsck/dumpe2fs，除迁移偏移外复制计划逐字段一致，A/B 根只读保护及 home 挂载通过。原始未改镜像的独立 UEFI 启动也通过。
- 语言源代码的五项安装/重复/共享 home/恢复检查通过，最终新增 LC_MESSAGES=C/en_US 覆盖和重复分组保留检查通过。实际 A/B 根组件测试以 C 消息语言、德语 LC_TIME 和重复的无关 KDE 分组为前置，部署及重复部署通过，最终按只读方式挂载并执行未修改的生产语言校验代码通过。KDE 工具以 KDE_HOME_READONLY=1 禁用自身配置不可写提示，避免无图形环境中弹窗阻塞。复审发现的重复分组误报已修复后复验。实际镜像测试是语言组件范围；不冒充原有完整事务镜像上的重新新装验收。
- 两项独立代码审查完成；复制算法无需修正，语言校验的 P2 问题已修正并复审。源码构建零警告零错误，14 项便携安装器 smoke 通过。未执行完整图形桌面和 Steam 账户界面语言验收。
- 用户此前确认的实机测试对应空间/日志/界面修复，不覆盖本轮新增的复制算法。代理不对用户物理磁盘或主机固件执行测试写入；虚拟盘、源码检查和实机验收分别记录。
