# ONEXPLAYER 3 SteamOS 安装助手

在 Windows 中准备 SteamOS，安装到选定的 GPT 未分配空间。支持内置盘与 Windows 共存、外部 SD / SSD 完整系统、OXP3 设备适配与插件预装，以及可选的 rEFInd 双系统启动菜单。

当前整合版为 **OXP3 SteamOS 0.1.0 Beta**（`0.1.0-beta`）；默认系统目标为 **SteamOS 3.10 / build 20260924.1000**。本文与 [安装指南](docs/INSTALLATION_GUIDE.md) 按 **2026-10-14 当前代码**整理。普通启动已开放真实安装与分区删除，写入完成后仍需在掌机验证启动和硬件功能。

## 快速开始

1. 备份目标数据，保存 BitLocker 恢复密钥（如启用），准备恢复介质并连接电源。
2. 完整解压工具包，运行根目录 `SteamOSInstaller.exe`，处理 Windows 管理员提示。保留所有配套目录。
3. 在配置页中选择工作空间。实盘安装至少预留 **45 GiB** 可用空间，建议 **64 GiB**；额外下载、源镜像和旧任务另占空间，后续阶段还会复查实际需求。
4. 首次打开安装位置自动读取磁盘，读取时按钮旁显示“正在读取…”。选择至少 **64 GiB 连续未分配空间**，可选 **64G、100G、使用全部空间**或输入有效容量；界面单位均为 GiB。外部 SD / SSD 为 beta。
5. 按“安装位置 → 准备系统（恢复镜像 → 3.10 镜像）→ 选择安装内容 → 确认方案 → 启动器安装 → 安装进度 → 完成”操作。3.10 `.raucb` 下载或本地选择后可继续，点击“开始安装”后才联网重建；按需选择组件和 rEFInd。
6. 完成后导出日志、保存任务记录，通过设备 UEFI 启动菜单分别验证 SteamOS 和 Windows。

实盘安装完成后自动在 Windows 当前用户桌面生成 **重启到 SteamOS.bat**。双击后处理管理员提示并确认重启；内置安装指定下一次启动 `SteamOS (OXP3)`（安装了 rEFInd 时先进入菜单），外部安装进入 UEFI 设置供手动选择外部盘。脚本独立运行，保留默认启动顺序；生成失败会在完成页提示，不影响已完成的系统写入。

没有足够空间时，可对允许删除的数据分区执行“删除选定分区…”。**这是单独确认后立即执行的删除，清空整个分区，退出安装器不能撤销。** 工具不自动缩小 Windows 分区。首次使用请完整阅读 [安装与测试指南](docs/INSTALLATION_GUIDE.md)。

## 当前能力与边界

| 功能 | 当前代码行为 |
| --- | --- |
| 内置双系统 | 选择 NVMe / SATA 的 GPT 未分配空间，追加八个 SteamOS 分区，保留当前已有分区 |
| 外部完整系统 | 选择非系统 USB / SD / MMC 设备的 GPT 未分配空间，安装可启动系统；不是制作恢复 U 盘 |
| 安装容量 | 默认 64 GiB；支持 100 GiB、更大自定义容量和使用全部所选空间。准备阶段扩展 home 分区与文件系统，写入布局必须与所选容量一致 |
| 空间分配 | 系统及启动约占 24.375 GiB，其余用于 home 数据分区；可单独把所选连续区域的剩余空间创建为 NTFS，1 MiB 对齐（满足 4K 对齐）、4096 字节簇。确认后立即操作 |
| 工作空间 | 配置页中可更换本地专用文件夹并保存；下载、升级缓存、镜像准备和任务使用同一目录。切换不会搬移或删除旧文件 |
| 空间预检 | 实盘工作空间至少 45 GiB，建议 64 GiB；演练另计 80 GiB 测试盘。稀疏镜像转换按数据范围检查并保留 8 GiB 余量，预算不是占用上限 |
| 安装总进度 | 准备 32%、组件配置及复核 43%、rEFInd 3%、写入及读回 22%。显示两位小数和固定阶段编号，跨分区累计；详情见 [进度及容量估算](docs/INSTALLATION_PROGRESS.md) |
| 磁盘条件 | GPT、512 字节逻辑扇区、在线且可写；不自动初始化 RAW 盘、转换 MBR 或擦除整盘 |
| 删除分区 | 支持符合保护条件的普通数据分区，以及 Windows 无法识别文件系统的 Linux／其他 GPT 分区；后者无法检查内部文件，需确认整个分区可清空。独立确认后立即删除 |
| 删除保护 | 拒绝系统、启动、EFI、MSR、恢复、BIOS 引导、实际受保护／只读或元数据不足的分区，以及 Windows、安装助手、工作空间、临时文件、页面文件等所在卷；未识别分区额外核对原生 GPT 属性 |
| 磁盘读取 | 确认安装前安全启动与 BitLocker 提示后自动读取，读取状态显示在按钮旁；可手动刷新。空盘/空读卡器不会使整个读取失败；分区快照不完整时禁止安装和删除 |
| 系统来源 | 恢复镜像作为基础容器，ZIP 为推荐；3.8.14 是恢复镜像标签。独立 3.10 子页支持 `.raucb` 与已重建 `rootfs.img`，更新包重建延后到开始安装 |
| 组件 | 设备修复、Decky 及预装插件按选项和依赖部署；可选资源缺失或不兼容时跳过并在完成页说明原因，I/O、写入及引导错误仍停止安装；KDE 语言单独设置 |
| rEFInd | 默认关闭；部署到新 SteamOS EFI 分区，可选默认系统、一直等待或 1–3600 秒倒计时；固件触屏仍待验收 |
| 重启进入 Windows | 默认预装 0.1.1 Decky 按钮和桌面快捷方式，依赖 Decky；确认后设置一次性 BootNext。权限、图标尺寸与桌面确认框修复已同步，用户实机重启进入 Windows 成功，见 [说明](docs/WINDOWS_REBOOT.md) |
| 调试模式 | 默认关闭；开启后显示高级工具、示例布局和开发镜像选项。关闭会清除示例选择和开发镜像模式 |
| 停止与恢复 | 停止按钮保留窗口供导出日志；关闭窗口先停止、释放资源并保存日志后自动退出。停止不回滚；实盘中断尚无自动续写，继续上次演练仅适用于工具识别的虚拟盘任务 |
| 日志导出 | 进度或结果页导出 ZIP，包含完整任务文本日志与诊断记录；运行中可导出当前快照，不含系统镜像 |

删除后预览中的“保留已有分区”，指刷新后仍存在的分区，不会恢复此前删除的文件。

## 安装前：安全启动与 BitLocker

当前 SteamOS / rEFInd 引导要求先在 **BIOS / UEFI 关闭安全启动（Secure Boot）**。如 Windows 启用了 **BitLocker / 设备加密**，请先在 Windows 中备份并确认可用的恢复密钥，再暂停 BitLocker 保护，然后关闭安全启动并返回 Windows。

关闭安全启动或更改默认启动顺序可能使加密硬盘无法自动解锁，进入 Windows 时要求恢复密钥；没有密钥时可能无法访问数据。暂停保护会减弱数据保护，安装后确认 Windows 正常启动，再恢复 BitLocker 保护，不要长期暂停。详见 [微软 BitLocker FAQ](https://learn.microsoft.com/en-us/windows/security/operating-system-security/data-protection/bitlocker/faq) 与 [暂停保护说明](https://learn.microsoft.com/en-us/troubleshoot/windows-client/windows-security/suspend-bitlocker-protection-non-microsoft-updates)。安装助手不会自动修改 BIOS、暂停加密保护或收集恢复密钥。

向导在进入“安装位置”前显示准备对话框；确认安全启动已关闭、加密恢复准备已完成后，才开放安装位置并自动读取磁盘。未准备好可直接退出；安装位置页保留再次查看提示的入口。

“启动器安装”页新增“**将启动管理器设为默认启动项（推荐）**”，内置实盘安装默认勾选，安装完成时把 `SteamOS (OXP3)` 排到 BIOS / UEFI BootOrder 首位，保留 Windows Boot Manager 及其余入口的相对顺序。勾选安装 rEFInd 时重启先进入菜单，否则直接启动 SteamOS。取消勾选保留原默认顺序，需要手动选择 SteamOS，可能仍先进入 Windows。外部盘安装和虚拟盘演练禁用该选项，不修改主机启动顺序。rEFInd 的“菜单默认系统”只控制菜单内选择。

固件写入前保存 `firmware-before.json`，读回核对后保存 `firmware-result.json`；失败时仅在固件状态仍匹配本次写入的情况下恢复原顺序。真实固件重启和 Windows / BitLocker 行为待实机验收。当前源码和新构建包含此改动，已有 ZIP 不会更新。

## 日志与排错

进度或结果页点击“导出详细日志…”，保存诊断 ZIP。界面只显示最近一部分输出，导出会读取已保存的完整日志；安装进行中导出的是当时快照。

任务目录位于 `<工作空间>/install-session-<任务ID>/`，完整界面日志为 `ui.log`，演练续写为 `ui-resume-*.log`。结果页可“打开任务文件夹”。发生写入中断时保留整个任务目录、`physical-state.json` 和 GPT 备份，不要仅保存截图，也不要直接删除新增分区或覆盖重装。

常见问题与反馈字段见 [指南：常见问题](docs/INSTALLATION_GUIDE.md#11-常见问题)。
